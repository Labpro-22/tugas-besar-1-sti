# Tugas Besar 1 IF2010 Pemrograman Berorientasi Objek

## Cara Compile dan Run
1. ke `root` directory jalanin command `make`
2. ke `bin` directory jalanin command `./game`

## Alur Program
1. Input file config yang diinginkan
2. Memilih mode apakah melanjutkan permainan lama (muat savegame = y) atau memulai permainan baru
3. Mendaftarkan pemain satu per satu
4. Permainan dimulai! yippie :)

3. Press Alt + D, there will be a preview
